\# EvidenceRAG



EvidenceRAG is an AI-powered document intelligence platform designed to answer questions from user-provided documents using grounded retrieval and citation-backed generation.



\## Project Status



In active development.



The system is being built incrementally with a focus on:



\- Hybrid document retrieval

\- Reranking

\- Grounded answer generation

\- Source-level citations

\- Retrieval and generation evaluation

\- Production-oriented API design
